# 🧸 Mexico Toy Sales Data Analytics Project

## 📌 Project Overview

This project presents an end-to-end data analytics solution based on the **Mexico Toy Sales dataset** sourced from Maven Analytics. It simulates the operations of a fictional retail chain, *Maven Toys*, and focuses on extracting actionable business insights through data analysis and visualization.

The project covers the complete analytics workflow — from data exploration and cleaning using Python to building interactive and insightful dashboards in Power BI.

---

## 🎯 Objectives

* Analyze sales performance across products, stores, and time
* Identify high-performing and underperforming products
* Evaluate store-level performance and regional trends
* Understand profitability and cost dynamics
* Build interactive dashboards for business decision-making

---

## 📂 Dataset Description

The dataset includes transactional, product, and store-level data with the following key columns:

* **Transaction Details:** sale_id, date, units
* **Store Information:** store_id, store_name, store_city, store_location, store_open_date
* **Product Information:** product_id, product_name, product_category, product_cost, product_price
* **Time Attributes:** month, month_num, month_name
* **Financial Metrics:** revenue, total_cost, profit, profit_margin, profit_margin_%
